# 🏛️ Достопримечательности Ижевска

Веб-приложение-путеводитель по достопримечательностям столицы Удмуртии - города Ижевска. Проект представляет собой полнофункциональный сайт с системой аутентификации пользователей, каталогом достопримечательностей и подробной информацией о каждом объекте.

## 🌟 Особенности проекта

- 🎯 Полный каталог достопримечательностей - 14 основных мест Ижевска с фотографиями и описаниями
- 🔐 Система аутентификации - регистрация и вход для пользователей
- 📱 Адаптивный дизайн - корректное отображение на всех устройствах
- 🏷️ Категоризация - удобная фильтрация по типам достопримечательностей
- 📖 Детальная информация - расширенные описания с историческими фактами
- 🎨 Современный UI/UX - приятный и интуитивно понятный интерфейс

## 🗂️ Категории достопримечательностей

- 🏛️ Архитектура
- 🏛️ Музеи
- 🌳 Парки
- 🗿 Памятники
- 🎪 Развлечения
- 🎭 Культура
- 🚶 Прогулки
