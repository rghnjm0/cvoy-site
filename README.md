# 🏛️ Удмуртия: Краудсорсинговая платформа уникальных мест

Веб-приложение для сбора и публикации уникальных мест Удмуртской Республики. Платформа позволяет пользователям добавлять, оценивать и комментировать интересные места, формируя сообщество любителей родного края.
## ✨ Особенности
- 🌍 Краудсорсинг - любой пользователь может добавлять места

- ✅ Модерация - система проверки новых публикаций

- ⭐ Рейтинг и комментарии - обсуждение и оценка мест

- 📱 Адаптивный дизайн - работает на всех устройствах

- 🔍 Поиск и фильтрация - по названию, категории, описанию

- 📸 Загрузка фотографий - поддержка изображений

- 👥 Социальные функции - лайки, комментарии, профили

- 🛡️ Админ-панель - управление контентом

## 🎨 Категории мест
- 🏛️ Архитектура - храмы, здания, мосты

- 🌳 Природа - горы, реки, озёра, леса

- 🏛️ Музеи - музеи и выставки

- 🌳 Парки - парки и скверы

- 🗿 Памятники - памятники и скульптуры

- 🎭 Культура - театры, культурные центры

- 📜 История - исторические места

- ⛪ Религия - религиозные объекты

- ⚽ Спорт - спортивные сооружения

- 🎪 Развлечения - цирки, аттракционы

- 🔶 Другое - прочие интересные места

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.8+
- Flask
- SQLite3
- PyCharm
  
### Клонирование из GitHub

- Откройте PyCharm
- Нажмите Get from VCS
- Вставьте URL репозитория
- Выберите папку для проекта
- Нажмите Clone
  
## 🔧 Функционал
Для всех пользователей:
- 📍 Просмотр всех мест

- 🔍 Поиск по названию, описанию, адресу

- 📂 Фильтрация по категориям

- 👁️ Просмотр детальной информации о месте

Для зарегистрированных пользователей:
- ➕ Добавление новых мест

- ✏️ Редактирование своих мест

Для администраторов:
